# Схема базы данных «Автосервиса»

Десять сущностей. Схему создаёт миграция `pb_migrations/1_init.js`, руками в панели
ничего заводить не нужно. Поля `id`, `created`, `updated` у каждой коллекции.
Поле `deleted_at` — логическое удаление: пустая дата значит, что запись действует.

## Связи

| Тип | Связь | Как устроено |
| --- | --- | --- |
| один к одному | клиент — клубная карта | `club_cards.client`, уникальный индекс по `client` |
| один к одному | пользователь — клиент / мастер | `users.client`, `users.mechanic` |
| один ко многим | марка → модели | `car_models.brand` |
| один ко многим | модель → автомобили | `cars.model` |
| один ко многим | клиент → автомобили | `cars.client` |
| один ко многим | категория → услуги | `services.category` |
| один ко многим | автомобиль → записи, мастер → записи | `appointments.car`, `appointments.mechanic` |
| многие ко многим | автомобили ↔ мастера | `cars.mechanics` (до трёх) |
| многие ко многим | записи ↔ услуги | `appointments.services` |

## Коллекции

| Коллекция | Поля (обязательные — *) |
| --- | --- |
| `brands` — марки | name*, country* |
| `car_models` — модели | brand* → brands, name* |
| `clients` — клиенты | last_name*, first_name*, middle_name, phone, email, discount 0–30, registered_at |
| `club_cards` — клубные карты | client* → clients, number* `AS-123456`, level* standard/silver/gold, issued_at*, expires_at*, bonus_points |
| `mechanics` — мастера | last_name*, first_name*, middle_name, phone*, grade* 1–6, experience, hired_at |
| `cars` — автомобили | plate*, vin* (17 знаков), model* → car_models, year*, mileage, fuel* petrol/diesel/gas/hybrid/electric, client* → clients, mechanics* → mechanics (1–3) |
| `service_categories` — категории услуг | name* |
| `services` — услуги | name*, category* → service_categories, price*, duration* (мин) |
| `appointments` — записи на обслуживание | car* → cars, mechanic* → mechanics, services* → services (1–20), starts_at*, ends_at, status* planned/in_progress/done/cancelled, subtotal, discount_percent, discount_source none/card/personal, total, comment |
| `users` — учётные записи (встроенная) | username*, last_name, first_name, role* client/mechanic/admin, client → clients, mechanic → mechanics |

`mechanic_busy` — представление (view): только время записей мастеров без подробностей.
По нему клиент при записи видит, когда мастер занят.

## Правила доступа

`@request.auth` — вошедший пользователь; у гостя поля пустые, поэтому гость не видит ничего.

| Коллекция | Чтение | Создание | Изменение | Физическое удаление |
| --- | --- | --- | --- | --- |
| brands, car_models, service_categories, services, mechanics | все вошедшие | мастер, админ | админ; мастер — только неудалённые | админ |
| clients | мастер, админ; клиент — себя | мастер, админ | админ; мастер — неудалённые | админ |
| club_cards | мастер, админ; клиент — свою | мастер, админ | мастер, админ | мастер, админ |
| cars | мастер, админ; клиент — свои | мастер, админ | админ; мастер — неудалённые | админ |
| appointments | мастер, админ; клиент — своих машин | мастер, админ; клиент — для своей машины, статус «запланирована» | админ; мастер — неудалённые; клиент — только отмена своей запланированной | админ |
| users | админ; каждый — себя | регистрация только с ролью client | админ; каждый — себя без смены роли и связей | админ |

Восстановление удалённой записи (очистка `deleted_at`) возможно только у администратора:
мастер не может менять запись, у которой `deleted_at` заполнено.

## Серверные правила (`pb_hooks`)

1. **Запись на обслуживание** (создание и изменение):
   - окончание = начало + сумма норм времени услуг;
   - работы должны уложиться в 9:00–20:00 по Москве, иначе **422** с ошибкой у поля `starts_at`;
   - у мастера не должно быть другой активной записи, пересекающейся по времени
     (`начало < чужое окончание && окончание > чужое начало`), иначе **409**
     «Мастер занят с … до …»;
   - стоимость: `subtotal` = сумма цен услуг; скидка = большая из персональной скидки
     клиента и скидки по клубной карте, действующей на дату записи (стандартная 0 %,
     серебряная 5 %, золотая 10 %), но не больше 15 %; `total` = `subtotal` минус скидка.
   Эти поля всегда пересчитывает сервер — присланные значения не используются.
2. **Физическое удаление** записи, на которую ссылаются другие (марка с моделями, модель
   с автомобилями, клиент с автомобилями, категория с услугами, услуга в записях, мастер
   с записями или закреплённый за автомобилем, автомобиль с записями) — **409**.
3. **Регистрация**: новому клиенту создаётся карточка клиента и связывается с учётной записью.
4. Администратор не может изменить собственную роль и удалить себя — **409**.

Срок действия токена — 15 минут; приложение обновляет его через `auth-refresh` заранее.
