# PocketBase для «Автосервиса»

PocketBase — база данных SQLite с готовым REST API и панелью управления в одном
исполняемом файле. Серверного кода приложения нет: схема описана миграцией, а
несколько правил предметной области — короткими хуками.

| Папка / файл | Что это |
| --- | --- |
| `pb_migrations/1_init.js` | коллекции, связи, правила доступа, настройки — применяются сами при запуске |
| `pb_hooks/` | серверные правила: запись к мастеру, стоимость, запрет удаления связанных записей |
| `seed.mjs`, `seed-data.json` | демонстрационные данные |
| `схема.md` | описание схемы и правил для чтения |
| `pb_data/` | база (создаётся при запуске, в репозиторий не попадает) |

## Запуск

1. Скачать архив для своей системы со страницы релизов
   https://github.com/pocketbase/pocketbase/releases (проверено на v0.40.4) и положить
   `pocketbase.exe` в эту папку.

2. Создать суперпользователя (владельца базы) — при первом запуске применится и миграция:

   ```bash
   ./pocketbase.exe superuser upsert admin@autoservice.local Autoservice2026
   ```

3. Запустить сервер и не закрывать окно, пока работает приложение:

   ```bash
   ./pocketbase.exe serve --http 127.0.0.1:8090
   ```

   REST API — http://127.0.0.1:8090/api/, панель управления — http://127.0.0.1:8090/_/.

4. В другом окне залить демонстрационные данные (Node.js 18+):

   ```bash
   node seed.mjs            # залить, если база пустая
   node seed.mjs --reset    # очистить и залить заново
   ```

На Windows хуки не перечитываются на лету: после правки `pb_hooks` сервер нужно
перезапустить.

## Учётные записи для проверки

| Логин | Пароль | Роль |
| --- | --- | --- |
| admin | Admin#2026 | администратор |
| master | Master#2026 | мастер (Громов Виктор Алексеевич) |
| client | Client#2026 | клиент (Иванов Сергей Петрович) |

Суперпользователь панели управления: `admin@autoservice.local` / `Autoservice2026`.
Это учебная база, секретов в ней нет.

## Запуск приложения с этим сервером

```bash
flutter run -d chrome --web-hostname 127.0.0.1 --web-port 5000 --dart-define=API_BASE_URL=http://127.0.0.1:8090
```

И приложение, и сервер открываются по `127.0.0.1`: для браузера `localhost` — другой
адрес со своим хранилищем, вход бы не сохранялся.
